Jarvis - Privacy policy

Last updated: 2026-09-30

Jarvis is a personal application used only by its developer. It is not distributed to, and does not collect data from, any other person.

What it accesses

With the developer's own permission, Jarvis uses the Google Calendar API (scope calendar.events) to read the developer's calendar events and to create, change or delete events that Jarvis itself created. It does not access any other Google data.

How data is used and stored

Calendar data is used only to answer the developer's requests and to manage the developer's schedule. It stays on the developer's own computer and home server. It is not sold, shared, transferred to third parties, or used for advertising. The access credentials are stored only on the developer's own server.

Sharing

Jarvis sends an invitation to another person only when the developer approves it first.

Revoking access

Access can be withdrawn at any time at myaccount.google.com/permissions.

Contact

Questions: open an issue at github.com/ambroz11.

Jarvis's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
